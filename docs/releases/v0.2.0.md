# FIB-NET v0.2.0 — Julia correlation functions and manuscript consistency

FIB-NET v0.2.0 makes the public correlation-function evaluation path consistent
with the implementation used for the revised manuscript artifacts.

## Highlights

- Replaced the former in-house Boolean surface-correlation calculation with
  `CorrelationFunctions.jl` v0.14.0.
- Added a native per-slice 2D bridge using `Directional.surf2`,
  `Directional.surfvoid`, `ConvKernel(7)`, and non-periodic boundaries.
- Kept genuine volume processing available as a separate 3D mode.
- Added paired manual/predicted evaluation with valid-pair-weighted x/y curves,
  manuscript NRMSE, physical lag distances, and `E_CF`.
- Added real-Julia integration tests for 2D arrays, phase convention,
  non-periodic sample counts, and the synthetic interface case.

## Validation

- Authoritative Julia correlation tests: 16 passed.
- Complete Python test suite: 26 passed.
- Ruff lint and formatting checks passed.
- The documented paired 2D correlation CLI completed successfully.
- No model training or inference was rerun for this release.
